# Latihan Tiket Online Jakarta - Malaysia

Latihan membuat form tiket online menggunakan PHP.

## Tampilan Form

Form terdiri dari:

- Nama
- Pilih Kode Pesawat
- Pilih Kelas
  - Eksekutif
  - Bisnis
  - Ekonomi
- Jumlah Tiket
- Tombol Simpan
- Tombol Batal

## File

`latihan-tiket-online.php`

## Teknologi

- PHP
- HTML
- XAMPP

## Cara Menjalankan

Jalankan menggunakan XAMPP, kemudian buka:

http://localhost/latihan-tiket-form/latihan-tiket-online.php
